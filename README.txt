OWNDAYS 統計－外部輕量版
=========================

內容：
- index.html：收藏夾安裝頁
- counter.js：統計核心（沿用收藏夾版 1.10）

部署：
1. 將 index.html 及 counter.js 放在同一個資料夾。
2. 將整個資料夾部署到支援 HTTPS 的靜態網站，例如 Vercel 或 Cloudflare Pages。
3. 開啟部署後的 HTTPS index.html。
4. 確認頁面自動顯示 https://.../counter.js。
5. 將「OWNDAYS 統計－外部版」拖到收藏夾列，或下載收藏夾匯入檔。

門市使用：
1. 同事自行在 Front2 輸入店舖番號及登入密碼。
2. 開啟「當日列表」，確認分店正確及開單日期為今日。
3. 按收藏夾「OWNDAYS 統計－外部版」。
4. 面板出現後按「開始統計」。

注意：
- 只使用自己部署及信任的 counter.js 網址。
- 現有收藏夾版 1.10 應保留作後備。
- 更新 counter.js 後，各店下次按收藏夾會自動載入新檔案。
- 工具不讀取或保存登入密碼。
