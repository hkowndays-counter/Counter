使用方法

  1. 先將本資料夾完整部署到支援 HTTPS 嘅靜態網站；index.html 同 counter.js 必須放喺同一層。
  2. 用部署後嘅 HTTPS 網址開啟本頁，程式網址會自動填好。
  3. 將「OWNDAYS 統計－外部版」拖到門市瀏覽器收藏夾列，或者下載匯入檔。
  4. 同事照常登入 Front2、確認正確分店及今日開單日期，再按收藏夾。
收藏夾會做乜？

先確認目前係 Front2 當日列表，再載入你指定嘅 counter.js。載入失敗或超過 15 秒會顯示提示；不會讀取或保存密碼。

只可填入你自己部署及信任嘅 HTTPS 程式網址。外部 JavaScript 會在 Front2 頁面執行，因此唔應使用陌生人提供嘅網址。現有收藏夾版 1.10 請保留作後備。
